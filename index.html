One-time setup: Microsoft app + hosting
  1. Put this index.html in a GitHub repository and turn on GitHub Pages (Settings → Pages → deploy from branch). Your site address looks like https://yourname.github.io/quiz/.
  2. Go to portal.azure.com → App registrations → New registration. Supported account types: Personal Microsoft accounts only. If the portal asks, create the free Azure account; app registrations cost nothing.
  3. Redirect URI: platform Single-page application (SPA), address = this page's exact address:
  4. Copy the Application (client) ID into the box above and press Sign in. Approve the OneDrive permission when asked.
  5. Optional but recommended: in Excel, click inside your data and press Ctrl+T to make it a table, then pick that table here.
